# Data Cleaning & Preparation - Telco Customer Churn

## Objective

This project focuses on transforming raw customer data into a clean and machine-learning-ready dataset.

## Tasks Performed

- Loaded raw dataset
- Converted incorrect data types
- Removed blank values
- Handled missing values
- Removed duplicate records
- Encoded categorical variables
- Performed feature engineering
- Checked outliers
- Exported cleaned dataset

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Output

A fully cleaned dataset ready for Exploratory Data Analysis (EDA) and Predictive Modeling.
